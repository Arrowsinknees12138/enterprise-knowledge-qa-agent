# 复盘

最难的是把“识别冲突”和“调查冲突”变成可以单独验证的行为。首次实跑中，模型已发现矛盾，但直接结束。用两个已读引用和一次后续新检索作为冲突结束的前置条件后，测试可以核对模型是否真做了补查。补查词和下一步仍由模型决定。

把答案限制为引用原文后，可以通过替换语料直接验证数据是否真正影响输出。把无命中与工具失败区分开，也使 Trace 能解释模型是缺资料、缺证据还是缺执行预算。

用时按建库至首次提交计，约 10 分钟。此处记录的是本次 Codex 实施与验证用时。候选人的独立复跑和审阅用时待据实补充。

随后追加约 3 分钟的审核复核。用同一问题对照替换原文前后的模型动作，并验证检索命中但原文缺少所问字段时的停止行为。[复核记录](03-evaluation.md)

语料扩展后，邮箱附件与云盘共享关键词、正式员工与外包人员有不同规则。实跑时模型在读到目标文档后有过提前结束的尝试，执行器返回仍有未核对候选，模型随后读取另一个候选再完成。多查一次的成本可从 Trace 的工具预算中看到。[附件干扰用例](../examples/deepseek/11-attachment-noise.json) · [人群适用用例](../examples/deepseek/14-audience-scope.json)

待扩展项包括更大语料的检索召回评估和跨模型重复运行的稳定性测试。
