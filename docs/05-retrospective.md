# 复盘

最难的是把“识别冲突”和“调查冲突”变成可以单独验证的行为。首次实跑中，模型已发现矛盾，但直接结束。用两个已读引用和一次后续新检索作为冲突结束的前置条件后，测试可以核对模型是否真做了补查。补查词和下一步仍由模型决定。

把答案限制为引用原文后，可以通过替换语料直接验证数据是否真正影响输出。把无命中与工具失败区分开，也使 Trace 能解释模型是缺资料、缺证据还是缺执行预算。

用时按建库至首次提交计，约 10 分钟。此处记录的是本次 Codex 实施与验证用时。候选人的独立复跑和审阅用时待据实补充。

待扩展项包括更大语料的检索召回评估、无关命中和复杂冲突样例，以及跨模型重复运行的稳定性测试。
